Comments can now span a range of lines. Select the lines in the diff body, then click the `+` to comment on the whole selection — for both local (Unstaged/branch/session) comments and PR review comments, which post as GitHub multi-line comments (`start_line`). The selected range is shown in the composer and on the comment, and a plain single-line click is unchanged.
