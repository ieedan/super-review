Review any branch read-only without checking it out.

Right-click a branch in the picker and choose **View Read-Only** to review its committed state (the Branch diff and Sessions) without touching the working tree — so an agent (or your own in-progress work) on another branch is never disrupted. The picker labels whatever branch is on screen; a pill in the top bar surfaces the branch that's actually checked out and clicks back to it. The Unstaged tab is hidden while reviewing read-only, since there's no working tree to commit against.
